# 90DaX

90DaX is a mobile-first 90-day personal execution system built with React and Vite.

## Focus
- Fitness and weight-loss consistency
- Google interview preparation: DSA, coding and system design
- English speaking and technical communication
- 8-hour sleep target

## UI
The signature interaction is a real-time vertical execution timeline. Completed activities become green points with white checkmarks, the current activity is highlighted, and upcoming activities remain muted.

## Run locally

```bash
npm install
npm run dev
```

Data is persisted in browser localStorage, so schedule and completion changes survive refreshes without requiring a backend.
